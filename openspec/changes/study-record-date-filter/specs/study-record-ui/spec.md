# Delta spec: study-record-ui

## MODIFIED Requirements

### Requirement: 月度学习日历

页面 SHALL 展示月度日历视图，标记已学习日期和今日。用户可切换月份查看历史学习记录。日历中的非未来日期 MUST 可点击，点击后按该日期过滤学习记录列表，并高亮选中日期。

#### Scenario: 查看当月日历
- **WHEN** 页面首次加载
- **THEN** 显示当前月份日历，已学习的日期以绿色背景标记，今日以主色蓝圆圈标记，未来日期灰色显示

#### Scenario: 切换月份
- **WHEN** 用户点击月份左右箭头
- **THEN** 日历切换到对应月份，summary API 重新请求该月数据，日历标记更新，且日期选中状态被清除，记录列表恢复整月展示

#### Scenario: 点击日期过滤记录
- **WHEN** 用户点击日历中某个非未来日期
- **THEN** 该日期高亮为选中态，下方学习记录列表仅显示该日期的记录

#### Scenario: 取消日期过滤
- **WHEN** 用户再次点击已选中的日期
- **THEN** 取消选中态，记录列表恢复为当月全部记录的分页展示
