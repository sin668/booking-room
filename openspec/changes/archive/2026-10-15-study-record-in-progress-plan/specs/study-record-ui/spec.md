# Delta spec: study-record-ui

## MODIFIED Requirements

### Requirement: 月度学习日历

页面 SHALL 展示月度日历视图，标记已学习日期（绿色圆点）和计划日期（未开始/进行中，橙色圆点）与今日。用户可切换月份查看历史学习记录。日历中的非未来日期与含计划类记录的未来日期 MUST 可点击，点击后按该日期过滤当前 Tab 的记录列表、根据日期与今日的关系自动切换 Tab，并高亮选中日期。图例 MUST 包含"已学习"和"未开始"。

#### Scenario: 查看当月日历
- **WHEN** 页面首次加载
- **THEN** 显示当前月份日历，已学习日期以绿色圆点标记，含计划类安排（未开始或进行中）的日期以橙色圆点标记，今日以主色蓝圆圈标记，未来日期数字灰色显示

#### Scenario: 切换月份
- **WHEN** 用户点击月份左右箭头
- **THEN** 日历切换到对应月份，summary API 重新请求该月数据，日历标记更新，且日期选中状态被清除，记录列表恢复整月展示

#### Scenario: 点击日期过滤记录
- **WHEN** 用户点击日历中某个可点击日期（含计划类记录的未来日期）
- **THEN** 该日期高亮为选中态，当前 Tab 的记录列表仅显示该日期的记录

#### Scenario: 点击日期自动切换 Tab
- **WHEN** 用户点击今日或晚于今日的日期
- **THEN** 记录列表 Tab 自动切换为"学习计划"；点击早于今日的日期时自动切换为"学习记录"；取消选中日期时保持当前 Tab 不变

#### Scenario: 取消日期过滤
- **WHEN** 用户再次点击已选中的日期
- **THEN** 取消选中态，记录列表恢复为当月当前 Tab 记录的分页展示

### Requirement: 学习记录列表

页面 SHALL 在日历下方以两个 Tab 展示记录："学习记录"Tab 展示已学习记录，"学习计划"Tab 展示计划类记录（未开始与进行中）；每次仅请求当前 Tab 对应 status 的数据。每条记录显示门店/课程名称、座位号或课时标题、时间段、学习时长、消费金额，并按记录状态显示"已学习"（绿色）、"进行中"（绿色）或"未开始"（橙色）标签；课程记录图标底色与状态一致（已学习/进行中绿色、未开始橙色）。

#### Scenario: 查看记录列表
- **WHEN** 页面加载或用户切换到"学习记录"Tab
- **THEN** 按日期倒序分页展示已学习记录，请求携带 `status=completed`

#### Scenario: 查看学习计划 Tab
- **WHEN** 用户切换到"学习计划"Tab
- **THEN** 按日期倒序分页展示计划类记录（未开始与进行中），请求携带 `status=upcoming`

#### Scenario: 未开始记录展示
- **WHEN** 用户存在未开始的自习室预约或课程课时（来源订单为待开始）
- **THEN** 对应记录以橙色"未开始"标签展示，课程图标为橙色，日期/时间段信息正常显示

#### Scenario: 进行中记录展示
- **WHEN** 用户存在进行中（in_progress）订单产生的计划记录
- **THEN** 对应记录以绿色"进行中"标签展示，课程图标为绿色

#### Scenario: Tab 内空态
- **WHEN** 当前 Tab 在该月没有记录
- **THEN** 展示对应空态文案（学习记录：暂无学习记录；学习计划：暂无学习计划）

#### Scenario: 加载更多记录
- **WHEN** 用户滚动到列表底部
- **THEN** 自动加载当前 Tab 的下一页记录，直到无更多数据
