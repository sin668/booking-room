# 课程预约 1V1 私人定制全套优惠与时间选择

## 动机

当前课程预约页面中，无论选择"固定班课"还是"1V1私人定制"，全套优惠价格都使用 `courses.full_package_price` 字段。1V1 私人定制应有独立的全套优惠价格字段 `full_custom_price`。

此外，1V1 私人定制模式下，上课时间应支持用户自主选择（周几 + 时间段），而非固定班课的"按课表上课"。

## 目标

1. 后端 `courses` 表新增 `full_custom_price` 字段
2. 前端课程预约页根据预约类型使用不同的全套优惠价格字段
3. 1V1 私人定制模式下，显示周几 + 时间段选择器（参考 seat-select 页面样式）

## 范围

- 后端：Course 模型新增字段、API 响应包含新字段
- 前端：course-booking.vue 页面逻辑调整、新增时间选择器 UI

## 非目标

- 不修改固定班课的全套优惠逻辑
- 不修改后端预约创建流程（时间选择仅前端展示）
