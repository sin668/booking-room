# activity-coupon-campaign Specification

## Purpose
定义发卡券活动管理能力，包括活动与卡券模板的关联配置、活动详情卡券展示、活动领券校验和已领取活动卡券的后续使用规则，确保运营活动可以安全发放并复用现有卡券体系。
## Requirements
### Requirement: 活动卡券配置模型
系统 SHALL 提供活动卡券配置能力，用于关联活动与卡券模板，并保存活动发放维度的库存、限领、领取时间、展示文案、排序和启用状态。卡券优惠规则、使用门槛、适用范围和卡券自身有效期 SHALL 继续由卡券模板定义。

#### Scenario: 创建活动卡券配置
- **GIVEN** 系统存在一个活动和一个启用的卡券模板
- **WHEN** 管理员为该活动新增一条活动卡券配置
- **THEN** 系统保存活动、卡券模板、总库存、已领取数量、每人限领数量、领取开始时间、领取结束时间、启用状态和排序
- **AND** 初始已领取数量为 0

#### Scenario: 活动没有关联卡券
- **GIVEN** 系统存在一个未配置活动卡券的已上架活动
- **WHEN** 用户查看活动详情
- **THEN** 系统返回活动详情
- **AND** 卡券列表为空数组

### Requirement: 活动详情卡券展示
系统 SHALL 在用户端活动详情中返回活动基础信息和可展示的活动卡券列表。卡券列表 SHALL 只包含活动已上架、活动卡券启用、卡券模板启用且未超过领取结束时间的配置。

#### Scenario: 查看包含卡券的活动详情
- **GIVEN** 活动已上架且关联了启用的活动卡券
- **WHEN** 用户请求活动详情
- **THEN** 系统返回 HTTP 200
- **AND** 响应包含活动标题、描述、封面、参与人数和活动卡券列表
- **AND** 每个活动卡券包含展示标题、说明、卡券类型、优惠规则、有效期、剩余库存、每人限领数量和用户领取状态

#### Scenario: 下架活动不展示领券入口
- **GIVEN** 活动已下架
- **WHEN** 用户请求活动详情
- **THEN** 系统不返回可领取卡券

### Requirement: 活动领券
系统 SHALL 提供活动卡券领取接口。领取时 MUST 校验登录态、活动上架状态、活动卡券启用状态、卡券模板启用状态、领取时间、库存、每人限领数量和用户重复领取数量。

#### Scenario: 成功领取活动卡券
- **GIVEN** 用户已登录
- **AND** 活动已上架，活动卡券启用，库存充足，用户未超过每人限领数量
- **WHEN** 用户领取该活动卡券
- **THEN** 系统返回 HTTP 200
- **AND** 系统创建一条用户卡券记录
- **AND** 用户卡券来源记录为该活动和该活动卡券配置
- **AND** 活动卡券已领取数量增加 1

#### Scenario: 未登录用户领取失败
- **GIVEN** 用户未登录
- **WHEN** 用户领取活动卡券
- **THEN** 系统返回 HTTP 401
- **AND** 不创建用户卡券记录

#### Scenario: 超过每人限领数量
- **GIVEN** 用户已领取该活动卡券达到每人限领数量
- **WHEN** 用户再次领取该活动卡券
- **THEN** 系统返回 HTTP 409
- **AND** 不创建新的用户卡券记录

#### Scenario: 库存不足
- **GIVEN** 活动卡券剩余库存为 0
- **WHEN** 用户领取该活动卡券
- **THEN** 系统返回 HTTP 409
- **AND** 不创建用户卡券记录

#### Scenario: 不在领取时间内
- **GIVEN** 当前时间早于领取开始时间或晚于领取结束时间
- **WHEN** 用户领取活动卡券
- **THEN** 系统返回 HTTP 400
- **AND** 不创建用户卡券记录

### Requirement: 已领取活动卡券可使用
系统 SHALL 将活动领取成功的卡券纳入现有用户卡券体系。活动下架后，用户已领取的卡券 MUST 继续按卡券模板的有效期、状态和适用范围规则参与预约用券。

#### Scenario: 活动下架后已领卡券仍可用
- **GIVEN** 用户已从活动领取一张未过期且未使用的卡券
- **AND** 管理员下架该活动
- **WHEN** 用户在预约流程查询可用卡券
- **THEN** 系统按既有卡券适用范围规则返回该卡券

#### Scenario: 已领活动卡券过期后不可用
- **GIVEN** 用户已从活动领取一张卡券
- **AND** 卡券模板有效期已过
- **WHEN** 用户查询可用卡券或预约可用卡券
- **THEN** 系统不将该卡券作为可用卡券返回
