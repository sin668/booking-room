## Why

当前管理后台（br-admin）缺少钱包流水管理和财务统计功能。运营人员无法在后台查看用户的交易明细、充值消费数据，也无法掌握平台资金概况。随着用户量和交易量增长，需要基本的财务管理工具来支持运营决策。

## What Changes

- 新增管理后台「钱包管理」模块，包含钱包流水列表页，支持按用户、类型、状态、时间范围筛选
- 新增财务统计概览，展示核心财务指标：总充值金额、总消费金额、总退款金额、平台净收入、活跃用户数等
- 新增后端管理 API，支持管理员查询所有用户的交易流水和财务统计数据
- 支持导出交易流水数据（CSV 格式）

## Capabilities

### New Capabilities
- `wallet-admin-api`: 管理端钱包 API — 交易流水查询（支持分页、筛选）、财务统计汇总接口
- `wallet-admin-ui`: 管理端钱包 UI — 钱包流水列表页、财务统计概览页、数据导出功能

### Modified Capabilities

（无现有 spec 需要修改）

## Impact

- **后端（br-server）**: 新增管理端钱包路由和服务方法，需要添加管理员权限校验
- **管理端前端（br-admin）**: 新增钱包管理菜单和页面，新增 API 调用模块
- **数据库**: 仅查询操作，不涉及 schema 变更
- **权限**: 需要在 RBAC 系统中添加钱包管理相关权限标识
