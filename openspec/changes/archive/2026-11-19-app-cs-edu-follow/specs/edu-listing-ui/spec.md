# edu-listing-ui Delta Spec

## MODIFIED Requirements

### Requirement: 详情页

br-app SHALL 提供供需信息详情页，展示完整信息（类型、标题、价格、区域、方式、描述、图片、可授课时间/标签、浏览次数）与发布者卡片（昵称、认证标识）。底部操作栏 SHALL 为：关注按钮（心形，切换对该供需信息的关注，复用 room-follows 接口 `follow_type=listing`）+ 客服按钮（戴耳机图标，打开平台客服 IM 会话）+ 主按钮（非发布者显示「立即联系」打开与发布者的会话，发布者显示「编辑」）。原「咨询」图标按钮 SHALL 由关注与客服按钮取代。

#### Scenario: 打开详情

- **Given** 广场中某条供需信息
- **When** 用户点击该卡片
- **Then** 跳转到详情页并展示该信息的完整内容与发布者信息

#### Scenario: 关注供需信息

- **Given** 已登录用户在供需详情页，该信息未关注
- **When** 用户点击关注按钮
- **Then** 以 `follow_type=listing` 创建关注记录，心形变红并提示「已加入关注供需」
- **And** 再次点击取消关注，心形恢复灰色描边并提示「已取消关注」

#### Scenario: 客服按钮打开平台客服会话

- **Given** 已登录用户在供需详情页
- **When** 用户点击客服按钮
- **Then** 打开与平台客服（用户 id `bd7f84cc-3d8b-480f-9327-30ee827cf386`）的 IM 单聊会话

#### Scenario: 立即联系保留

- **Given** 非发布者用户在供需详情页
- **When** 用户点击「立即联系」
- **Then** 打开与发布者的 IM 会话（无 IM 用户名时保留电话回退）
